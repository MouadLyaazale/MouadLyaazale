### Hi, I'm Mouad Lyaazale (معاد اليازل) 👋

I work in network infrastructure and security, in Morocco 🇲🇦. On my own time I build **[LYSS](https://github.com/lyss-project/lyss)**, an open, vendor-neutral security standard for network switches, and the free, read-only tool that checks them against it.

- 🛡️ **LYSS**: Telnet still on, SNMP "public", exploited firmware… find them on your switches in minutes, with the evidence and the fix. Cisco IOS, Cisco Business, HPE Aruba, Arista EOS, MikroTik RouterOS, SONiC, plus a firmware check for Zyxel GS1900. Three levels, up to 802.1X and ARP inspection.
- 🧪 Try it in your browser, nothing uploaded: [lyss.dev/audit.html](https://lyss.dev/audit.html) · or `pip install lyss`
